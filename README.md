# ChaChiLu Reading Library

A free static website ready for GitHub Pages. No paid hosting, build step, or framework required.

## Publish to GitHub Pages

1. Create a free account at https://github.com (if needed).
2. Create a **public** repository named `chachilu-reading-library` (or any name you like).
3. Upload **all the contents of this folder** to the repository root, preserving the `assets/` and `chapters/` folders.
4. Open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, then select branch **main** and folder **/(root)**. Save.
5. Once deployed, your URL will typically be `https://YOUR-USERNAME.github.io/chachilu-reading-library/`.

## Edit chapters

- Edit `chapters.js` to add entries to the chapter library. Each entry should link to a real HTML page you have created inside `chapters/`.
- Duplicate `chapters/chapter-1.html` to create another page, then replace the recap and metadata with your own content.
- Edit `index.html` to update your introduction and disclaimers.
- The cover is made entirely with HTML/CSS decorations. No external artwork is required.
